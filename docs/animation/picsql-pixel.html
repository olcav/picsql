PicSQL

A Java library that queries pictures with SQL. Every pixel is a row, every channel a column.

Space pauses, arrow keys change scene. 


  

    
Rows are pixels
r, g, b, x, y and rank() are columns. WHERE keeps or drops pixels.

    
Functions
lag, lead, sin, cos, tan, discr, flip, convolution masks, and butter (240, 227, 107).

    
Run it
java -jar picsql.jar "select g, b, r from ./face.bmp" out.bmp or --gui for the live editor.
